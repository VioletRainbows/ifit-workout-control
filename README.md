# iFit Workout Control

This is a super simple web-based treadmill workout generator for older iFit treadmills that use sound to control speed and incline.

To use, connect a device to the treadmill audio port, and press the ifit.com button, then press start on this app.

## Features

- Save settings in cookies
- Keep device awake
